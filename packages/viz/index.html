1Elegí el código

Tu proyecto o un ejemplo: el análisis es el mismo.

Arrastrá una carpeta o archivos .js / .ts acá

El análisis corre en tu navegador: el código no se sube a ningún servidor.

  1. GraphSAST lee los archivos JavaScript y TypeScript de la carpeta y sus subcarpetas (salvo node_modules, dist y similares).
  2. Sigue cada dato que entra desde afuera (por ejemplo req.query) por variables, funciones y archivos.
  3. Si llega a una operación peligrosa sin pasar por un filtro, lo marca en el grafo (2) y lo explica en Resultado (3).
